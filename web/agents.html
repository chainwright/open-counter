Connect your agent
to Lena's counter.

Any MCP client can read Small Garage and start a PayPal checkout. Prices, stock and delivery dates come from the shop's code, and nothing is charged until the buyer approves in PayPal.

Judge path: call the real MCP server below · step through a recorded purchase · see it in Lena's studio

1

The address

https://open-counter.onrender.com/mcp/

MCP over streamable HTTP. No key and no sign-up. Nine tools:

about_countersearch_counteritem_details delivery_estimatestart_checkoutquote_commission start_commission_checkoutleave_contactorder_status
2

Plug it in

Claude Desktop · claude_desktop_config.json

{
  "mcpServers": {
    "open-counter": {
      "command": "npx",
      "args": ["-y", "mcp-remote", "https://open-counter.onrender.com/mcp/"]
    }
  }
}

Or in Claude: Settings → Connectors → Add custom connector, and paste the address.

MCP Inspector, from a terminal

npx @modelcontextprotocol/inspector --cli https://open-counter.onrender.com/mcp/ --transport http --method tools/list

Any HTTP client

curl -s https://open-counter.onrender.com/mcp/ \
  -H 'content-type: application/json' -H 'accept: application/json, text/event-stream' \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/call","params":{"name":"search_counter","arguments":{"query":"green"}}}'

How paying works

    
start_checkout returns a PayPal approval link and two lines the agent must show the person:
      what they asked for, and what they're approving (items, shipping, total, ship date). Only the buyer's PayPal login can approve it,
      in PayPal's own window. The money is captured after that, and stock is checked again at capture. Made-to-order
      builds get a PayPal invoice instead: 50% deposit now, the balance before shipping.
