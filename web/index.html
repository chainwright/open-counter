    03 · HOW IT WORKS

    Legible. Payable. Still hers.

    Legible

    Lena's listings become a public counter: a page for people, a JSON card and an MCP server for agents. Agents get facts only — size, paint, stock, delivery — never guesses.

    Payable

    Any agent can start a PayPal order (Orders v2) priced on our server, line by line, with the buyer's address. Made-to-order builds get a PayPal invoice: half now, the rest before shipping.

    Still hers

    Nothing is charged until a human approves in PayPal. Her rules hold in code: US shipping only, any quantity up to the stock shown, made-to-order prices and build times from her table, stock checked again at capture.
