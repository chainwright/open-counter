    03 · HOW IT WORKS

    Legible. Payable. Still hers.

    Legible

    Lena's listings become a public counter: a page for people, a JSON card and an MCP server for agents. Agents get facts only — size, paint, stock, delivery — never guesses.

    Payable

    An agent can start a PayPal order (Orders v2) with the exact item, price and shipping, recomputed on our server. The person sees "you asked for" next to "you're approving".

    Still hers

    Nothing is charged until a human approves in PayPal. Lena's rules hold: ships to the US only, at most 2 per order, stock is checked again at capture.
